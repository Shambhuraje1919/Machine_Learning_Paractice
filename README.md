## 👋 About This Repo

This is my hands-on Machine Learning lab — **80+ notebooks** covering the full pipeline: data cleaning, EDA, feature engineering, classical ML, deep learning, and deployment. Every notebook is a real, runnable experiment, not copy-pasted tutorial code, and the repo runs on a **CI pipeline (GitHub Actions)** with a managed **conda environment**, which is more infra discipline than most fresher portfolios show.

> 📌 Skip to [🏆 Highlight Projects](#-highlight-projects) if you're a recruiter short on time.

## 🚀 Getting Started

```bash
git clone https://github.com/Shambhuraje1919/Machine_Learning_Paractice.git
cd Machine_Learning_Paractice

# Using conda (recommended — matches environment.yml)
conda env create -f environment.yml
conda activate <env-name>

# OR using pip
pip install -r requirements.txt

# Launch Jupyter
jupyter notebook
```
